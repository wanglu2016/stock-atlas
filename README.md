![股市星图使用指南](guide-poster.jpg)

把 A 股与港股放进一个可以旋转、缩放、切换指标的空间。从熟悉的一家公司出发，观察它与同行、经营邻居和另一市场之间的关系。所有交互在浏览器内计算，不调用大语言模型，不读取券商账户，不提交交易。

## 可以怎么玩

- **市场星图**：估值、经营、行情、综合四种空间，支持二维 / 三维、搜索、市场及业务筛选、指标权重。
- **经营双胞胎**：先按经营特征找邻居，再比较 PE / PB。金融与非金融分开，估值不参与经营相似度。
- **历史迁徙**：84 只固定样本的月末行情位置和单股轨迹；不会把今天的财报倒填到过去。
- **AH 镜像**：48 组人工配对，同发行人两地股份按手动输入汇率比较价格。
- **我的宇宙**：本地自选、相对权重、导入导出，以及组合的历史回撤、波动和平均两两相关性。
- **研究线索与快照记录**：从可解释的当前数据条件提出问题；数据版本更新后，可与本地记录比较。

第一次使用，建议走这条路线：**搜索公司 → 查看邻居 → 寻找经营双胞胎 → 加入我的宇宙 → 运行一次历史实验**。

## 数据版本与边界

当前为 **2026-11-02 的真实第三方数据快照，尚未自动每日更新**。数据源和完整计算方法可以从页面右上角“数据与方法”查看。

- 8718 只具有有效正报价的证券：A 股 5573、港股 3145。并非逐一核验的全部挂牌公司，部分证券可能停牌或带有特殊状态。
- A 股经营数据采用带公告日的 2026 年三季报。港股报告期尚未校准，暂不纳入经营双胞胎。
- 缺失指标不按零补齐，非正 PE 不参与估值距离。来源动态 PE 不是统一 TTM，跨市场财务口径并非完全可比。
- 星图是高维特征的 PCA 投影，会丢失部分信息。邻居排名在标准化特征空间计算，不按画面距离直接排名。
- 历史仅为固定存续样本，存在幸存者偏差；前复权可能回溯重算，不是严格的历史时点数据库，也不是现金分红再投资总回报。
- 组合实验不含税费，假设汇率固定；缺少全区间数据的股票会被明确排除，并重新归一化剩余权重。
- 尚未实现实时行情、全市场财务历史、历史相似市场匹配、盈利 / 估值 / 分红贡献归因。

本项目帮助发现值得核验的问题；估值差异不自动表示低估，AH 价差不等于可执行套利收益，历史表现也不保证未来。

## 本地运行

需要通过 HTTP 服务打开，不能双击 `index.html` 使用 `file://`：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000`。不需要 npm 安装或构建。仓库根目录就是静态网站，可使用 GitHub Pages 的 `main / (root)` 发布。

维护者可运行：

```sh
node scripts/check.mjs
python scripts/update.py
```

采集脚本使用 Python 标准库。第三方接口可能改变或限流；财报期目前固定为 2026Q3，换季更新应同步调整口径。采集失败会恢复两份 JSON 的旧版本。访客不会执行这些采集请求。
